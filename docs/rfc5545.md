# Writing recurrence rules (RFC 5545)

The `recurrence` field on `POST /events` and `PATCH /events/{id}` accepts recurrence
rules exactly as defined by [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545) (the
iCalendar standard also used by Google Calendar, Outlook, and Apple Calendar). This
doc is a practical reference for writing them — not the full spec, just what you'll
actually need.

## The shape of a rule

A rule is a single string, always prefixed with `RRULE:`, made of `KEY=VALUE` pairs
separated by semicolons:

```
RRULE:FREQ=WEEKLY;BYDAY=MO;COUNT=10
```

That line reads as: "repeat weekly, on Mondays, 10 times total."

In our API, `recurrence` is a list, since RFC 5545 technically allows combining
multiple rule lines (e.g. an `RRULE` plus an `EXDATE` to exclude a specific date).
For nearly all everyday use, you only need one `RRULE:` string in that list:

```json
{
  "summary": "Team standup",
  "start": {"dateTime": "2026-08-03T09:00:00", "timeZone": "America/Sao_Paulo"},
  "end":   {"dateTime": "2026-08-03T09:15:00", "timeZone": "America/Sao_Paulo"},
  "recurrence": ["RRULE:FREQ=WEEKLY;BYDAY=MO;COUNT=10"]
}
```

## The keys you'll actually use

### `FREQ` (required)

How often it repeats. One of: `DAILY`, `WEEKLY`, `MONTHLY`, `YEARLY`.

### `INTERVAL` (optional, default 1)

Skip every N periods instead of every one. Combine with `FREQ` to mean "every 2
weeks", "every 3 months", etc.

```
FREQ=WEEKLY;INTERVAL=2   # every other week
FREQ=MONTHLY;INTERVAL=3  # every quarter
```

### `COUNT` vs `UNTIL` (optional, pick at most one)

Two different ways to say when the series ends. Never use both together.

- `COUNT=10` — stop after 10 occurrences.
- `UNTIL=20261231T235959Z` — stop after this date/time (UTC, in `YYYYMMDDTHHMMSSZ`
  format — note the `Z`, it's required).

If you omit both, the event repeats forever.

### `BYDAY` (optional)

Which day(s) of the week. Two-letter codes: `MO`, `TU`, `WE`, `TH`, `FR`, `SA`, `SU`.
Comma-separate for multiple days:

```
FREQ=WEEKLY;BYDAY=MO,WE,FR   # Monday, Wednesday, Friday
```

For `FREQ=MONTHLY`, prefixing `BYDAY` with a number picks the Nth occurrence of that
weekday in the month (negative counts from the end):

```
FREQ=MONTHLY;BYDAY=2FR    # the second Friday of every month
FREQ=MONTHLY;BYDAY=-1FR   # the last Friday of every month
```

### `BYMONTHDAY` (optional)

A fixed day-of-month number, for things like "the 1st of every month" (rent, billing):

```
FREQ=MONTHLY;BYMONTHDAY=1     # the 1st of every month
FREQ=MONTHLY;BYMONTHDAY=-1    # the last day of every month
```

### `BYMONTH` (optional)

Restricts to specific months (1–12), mostly useful with `FREQ=YEARLY`:

```
FREQ=YEARLY;BYMONTH=3;BYMONTHDAY=15   # March 15th every year
```

## Common real-life recipes

| What you want | Rule |
|---|---|
| Every weekday (Mon–Fri), forever | `RRULE:FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR` |
| Every Monday, 10 times | `RRULE:FREQ=WEEKLY;BYDAY=MO;COUNT=10` |
| Every other Tuesday | `RRULE:FREQ=WEEKLY;INTERVAL=2;BYDAY=TU` |
| Rent due on the 1st of every month | `RRULE:FREQ=MONTHLY;BYMONTHDAY=1` |
| Last day of every month | `RRULE:FREQ=MONTHLY;BYMONTHDAY=-1` |
| Second Friday of every month | `RRULE:FREQ=MONTHLY;BYDAY=2FR` |
| Daily, until the end of 2026 | `RRULE:FREQ=DAILY;UNTIL=20261231T235959Z` |
| Yearly anniversary/birthday | `RRULE:FREQ=YEARLY` |

## Series vs. single occurrence

Once you create an event with `recurrence`, Google treats it as one **master
event** holding the rule. When you `GET /events`, we ask Google to expand it
(`singleEvents=True`), so you get back individual occurrences — each with its own
`id` and a `recurring_event_id` pointing back to the series.

- `PATCH`/`DELETE` using an **occurrence's `id`** — affects only that one occurrence
  (Google records it as an exception; the rest of the series is untouched).
- `PATCH`/`DELETE` using the **series' own `id`** (the one returned from the
  original `create` call, or a plain `GET /events/{id}` on it) — affects the whole
  series going forward.

## Trying it out

```sh
scripts/calctl.sh create "Team standup" "2026-08-03T09:00:00" "2026-08-03T09:15:00" \
    "America/Sao_Paulo" "RRULE:FREQ=WEEKLY;BYDAY=MO;COUNT=10"

scripts/calctl.sh list
```

See `scripts/calctl.sh`'s own `--help`/usage text for the full worked example.
